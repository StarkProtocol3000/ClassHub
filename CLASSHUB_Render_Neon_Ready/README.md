# CLASSHUB — Render + Neon deployment package

CLASSHUB is a responsive Flask web app for lecturer-managed class topic registration and assignments. This version supports PostgreSQL through Neon for hosted, persistent data and SQLite for local development.

## Included features

- First-time lecturer/admin account setup
- Lecturer creates classes and shares each class code
- Students self-register with a class code and sign in securely
- Students submit one topic each
- Duplicate topic titles are blocked within each class after case/whitespace normalisation
- Students see classmates' registered topics and review status
- Lecturer can approve or reject topics
- Lecturer can publish assignments and due dates
- Class detail page shows students, topics and assignments
- Responsive mobile and desktop interface
- `/health` endpoint for hosting health checks

## Deploy to Render with Neon

1. Put the contents of this folder at the **root** of your GitHub repository. The `render.yaml` file must be at the repository root (not inside an extra nested folder).
2. In Render, create a new Blueprint from that repository and select `render.yaml` as the Blueprint path.
3. Render reads the Blueprint and creates the `classhub` web service in Singapore.
4. In Neon, open the `classhub-db` project and click **Connect**. Select the `production` branch, database and role, then copy the pooled connection string if Neon offers the pooled option. Keep the connection string secret.
5. In Render, open the `classhub` service → **Environment**. Add `DATABASE_URL` with the Neon connection string. Save changes and redeploy.
6. Wait for the `/health` check to pass, then open the Render service URL.
7. Visit `/setup` once to create the lecturer/admin account. Create a class and share its class code with students.

`CLASSHUB_SECRET` is generated by Render from `render.yaml`. Do not replace it with a short or guessable value. Never commit Neon credentials or passwords to GitHub.

## Local development (SQLite)

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000. Without `DATABASE_URL`, the app uses `classhub.db` in this folder. When `DATABASE_URL` is set, it uses PostgreSQL instead.

## Notes

- The app creates its required database tables automatically on its first request.
- The free Render web service may spin down after inactivity; the first request after sleeping can take longer. Neon is the persistent database, not the Render filesystem.
- Before using real student data, add CSRF protection, rate limiting, email verification/password recovery, and review student privacy/retention requirements. Use strong admin credentials and share the app only with intended users.
- This package does not automatically transfer any existing local SQLite data into Neon. If the old local database contains records that must be retained, migrate them separately before switching users to the hosted app.
